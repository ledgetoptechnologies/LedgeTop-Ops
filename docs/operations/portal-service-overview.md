# Client portal assigned-service overview

The client portal Home surface shows the first page of services only when the
selected workspace has current root request readiness and the catalog page has
assignment proof matching that workspace's exact Project Alpha source, root
type, and root public ID.

A broad client-safe catalog, missing assignment proof, or proof for another
source is not labeled as assigned and is not shown. Workspace changes clear the
visible proof-bound page immediately and abort the prior request; a late response
cannot repopulate the new workspace.

The panel links to the existing request wizard. It adds no pricing, finance,
catalog merge, access grant, service enrollment, or activation behavior.
