# Connected pilot payload construction

`windows-connected-pilot-payload.ps1` produces an **unqualified local payload**, not an installer or release. It requires an exact commit, four-part version, .NET SDK 10.0.402 with a verified Microsoft-signed `dotnet.exe` host, and the pinned signed cloudflared binary and license. The host signature does not authenticate every SDK file. It archives tracked source from that commit into a fresh GUID directory under `%LOCALAPPDATA%\LedgeTopFilesConnectedBuilds`, then publishes a self-contained x64 pilot with the staging build marker and collects the checked-in runtime and helper notices.

Restore uses the explicitly provided local package source if given; otherwise it contacts NuGet.org. The receipt records the selected source, SDK and builder hashes, source archive hash, inventory hash, and construction options. It does not prove package-source immutability or byte-for-byte repeatability between restores. The compiled staging marker is not independent qualification. The receipt sets `freshGenerationStagingQualified=false` and `status=connected_payload_unqualified`, so the unsigned installer validator must refuse it. A separate evidence-backed qualification process bound to the exact source, version and payload is still required; this builder does not manufacture that evidence.

The output contains source, build artifacts, NuGet caches, payload, inventory, logs and receipt. It intentionally remains for inspection, including on failure; failures after root creation print its exact path. After the owning task has finished and any needed evidence is retained, remove only its exact GUID directory after confirming that no process uses it; do not remove the shared parent or another task's directory. This script does not run the application, installer, uninstaller, compiler for an installer, provider registration, authentication, signing or release publication.
