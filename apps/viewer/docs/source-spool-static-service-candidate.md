# Static source spool service: disabled skeleton

The candidate Compose file has only explicitly profiled design services, requires disposable host paths and an explicitly supplied image, and must not be applied to TrueNAS. Its mock API and worker mount services exit immediately. The copy entrypoint uses `flock -n -F` followed by Node, but the worker validates only static configuration and then exits 78: it has no network, database, copy or receipt functionality. No route or real source path is enabled.

The future service must not mount Viewer SQLite or the Docker socket. `sourceCopyHandoffContractCandidate.js` models a closed claim and receipt only: ordered files contain ID, relative path, byte size and hash; the dataset manifest digest hashes compact UTF-8 JSON of the same ordered entries excluding IDs, while the inventory digest includes IDs. Receipt equality is a shape check, not stored idempotency. This candidate's inventory digest is not the current spool seal digest, whose object format excludes relative paths. Zero-length entries pass this schema but the current copy candidate rejects them; integration must settle that discrepancy. The API-owned transactional request/outbox, capacity linkage, authenticated transport, actor and scope checks, replay-resistant worker authentication, receipt persistence, verified bytes and durable restart state remain unimplemented. A file path or a self-signed manifest is not authority. The lock path in this sketch lies in a writable spool and can be replaced unless independently protected; the actual image's `flock` availability and FD behavior are unverified. Multiple replicas, supervisor failure, host restart, ZFS locking, source and spool aliases, ACLs and physical capacity still require qualification. The child read-only overlay must be tested on the actual TrueNAS App configuration with the parent writable; local Docker behavior does not prove absence of alternate writable aliases. Beau controls the host App and filesystem settings. No deployment or NAS change is included.
