# Disabled local ingestion evidence candidate

`nativeIngestAckCandidate` is an explicit-opt-in local experiment with a test-only schema. It has no HTTP route, coordinator transport, production migration, automatic worker, deletion, or cleanup authority. It does not implement the proposed coordinator acknowledgement contract.

Before persisting an intent, the candidate requires an active `ready_for_review` Viewer attempt, matching active task, provider, ready managed model output and existing verified producer provenance. It checks the expected loopback provider origin, then rereads and verifies the retained extracted archive inventory against Viewer's stored receipt. A second transaction rereads the relevant database identity after that verification and either persists a fresh request/evidence UUID pair or returns the exact prior pair for the same evidence. Changed or missing evidence holds. It records Viewer's historical ZIP digest; rehashing extracted files is not independently rehashing the original ZIP.

The locally generated evidence UUID is **not** an ingestion commit ID: it is created after ingestion and is not atomically committed with the original ingestion. The expected environment and loopback origin are test inputs, not authenticated issuer, coordinator authority or generation. This candidate does not have an authenticated coordinator receipt digest or a cross-system identity contract. It cannot transmit, acknowledge receipt, authorize retention changes, or release any upstream data. Its SQLite check does not fence direct filesystem writers during or after hashing; protection from all local writers and power-loss behavior require separate qualification. The current implementation also rehashes the extracted inventory on each preparation and is not qualified for large production datasets.

The synthetic test uses real Viewer repository rows and a small local archive inventory. It holds before readiness and on changed bytes, verifies stable IDs after reopening the database, and holds if the attempt changes. It does not exercise lost network replies, an actual coordinator, an ingestion commit fence or a production acknowledgement.
