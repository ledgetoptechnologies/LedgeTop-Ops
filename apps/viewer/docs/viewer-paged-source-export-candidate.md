# Held Viewer source export candidate

`server/viewerPagedSourceExport.js` is an inactive, unmounted experiment. It reads the current finalized dataset, active task/attempt, stored attempt input inventory, and validated GCP snapshot/correspondences within one SQLite read transaction. It produces bounded canonical source and selected-frame byte streams compatible with the Processing `ltds-viewer-source-frames-v1` and `ltds-viewer-selected-frames-v1` candidate formats.

The generated ODM GCP selector is fixed to `text/plain` by the Viewer producer policy. Dataset file IDs are used as Processing closure object IDs; generated GCP uses `gcp_<attemptId>`, with a collision check. Raw GCP file IDs, paths, and hashes are checked against the immutable GCP correspondence snapshot. `correspondenceSha256` is SHA-256 of UTF-8 `JSON.stringify(evidence.correspondences)` bytes in stored row order. The selected order is copied from Viewer `inputInventory()` exactly: photos first, then other selected inputs, with generated `gcp_list.txt` replacing an older file of that basename.

The function does not accept or infer an authenticated principal, environment, authority, revocation epoch, transfer grant, or source-byte custody. Its result always says `held_authenticated_source_unavailable`, includes `enabled:false`, and has null authority/principal/epoch. It is not imported by an API route or worker. It is test-only framing evidence; it does not create access or authorize a Processing transfer. The proposed file-ID closure mapping and stream wire encoding still need cross-repository agreement and independent review.

Unsupported file classifications, zero-byte files, stale provenance, incomplete GCP evidence, invalid/current-attempt relationships, frame overflow, excessive preflight metadata (32 MiB), GCP evidence over 8 MiB, GCP content over 16 MiB, and nested transactions fail closed. SQL count/byte preflight runs before repository helpers materialize rows or parse GCP evidence. The producer uses a read-only `BEGIN` transaction and refuses to enter an already-open caller transaction, preventing it from committing or rolling back state owned by another operation. Raw frame size is measured including the JSON array brackets and excluding only the LF delimiter.
